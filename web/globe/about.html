About the Project

Mutnik Adventures is an interactive travel visualization project built to capture the journeys, memories, and destinations of friends and family across the globe. Each colored pin represents a unique traveler or couple — connecting memories through maps, photos, and shared experiences.

Tech Stack

Built with Flutter + Globe.gl (Three.js), powered by WebView integration. Designed to be lightweight, offline-capable, and easily extensible for new explorers.
